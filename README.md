# Анализ e-commerce данных Olist (SQL)

## Цель проекта
Проанализировать данные бразильского маркетплейса Olist, чтобы ответить на бизнес-вопросы о выручке, среднем чеке, качестве доставки и географии заказов.

## Данные
Датасет Olist содержит информацию о ~100 тыс. заказов за 2016–2018 гг.  
Скачать можно на Kaggle: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

## Инструменты
PostgreSQL (pgAdmin), SQL.

## Вопросы и результаты

### 1. Какие категории приносят наибольшую выручку?
- Лидер: **health_beauty** — **1 233 131.72** (9 465 единиц товара)
- Второе место: **watches_gifts** — **1 166 176.98** (5 859 единиц)
- Третье место: **bed_bath_table** — **1 023 434.76** (10 953 единицы)

**Интересный факт:** по количеству проданных единиц лидирует `bed_bath_table` (10 953), но по выручке — `health_beauty`. Это значит, что товары в `health_beauty` дороже, но покупают их реже.

### 2. Как менялся средний чек по месяцам?
- **Самый высокий средний чек:** октябрь 2016 — **152.17** (но всего 265 заказов — статистически ненадёжно). Среди месяцев с объёмом от 1000 заказов лидер — **январь 2017 (149.06)**.
- **Самый низкий средний чек:** декабрь 2016 — **10.90** (1 заказ). Среди «нормальных» месяцев — **июль 2017 (124.38)**.
- **Пик выручки:** ноябрь 2017 — **987 765.37** (7289 заказов). Это сезон распродаж («Чёрная пятница»).

### 3. Какой процент заказов доставлен с опозданием?
- Доля опоздавших доставок: **8.11%** (7 826 из 96 470 доставленных заказов).

### 4. В каких штатах доставка самая медленная?
- Самый медленный штат: **RR** — **29.4** дня в среднем (41 заказ).
- Второй: **AP** — **27.2** дня (67 заказов).
- Третий: **AM** — **26.4** дня (145 заказов).

## Выводы
- Категория **health_beauty** — лидер по выручке, но по количеству проданных единиц её обгоняет **bed_bath_table**. Это значит, что в `health_beauty` товары дороже, но покупают их реже.
- **8.11%** заказов доставлены с опозданием. Это не критично, но есть куда расти.
- Северные штаты (**RR, AP, AM**) — самые медленные по доставке (26–29 дней). Это логично из-за географии, но для бизнеса это риск: клиенты в этих регионах могут быть менее лояльны.
